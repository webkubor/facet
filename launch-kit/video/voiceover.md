# Voiceover — 60s（约 150 字）

你的 Markdown 教程导出 PDF，是不是总是丑得没法发？

这个开源工具，一条命令同时生成 A4 PDF 和小红书长图。

它不是把网页打印成 PDF——它先规划每一页放哪些知识点：封面、目录、学习地图、正文、回顾，短章节自动合并，不会孤零零占一整页。

内容规划好，八套教程模板和四套简历模板随便换：温暖手册、公众号杂志、莫兰迪研究档案，同一份 Markdown，气质完全不同。

还能把你喜欢的颜色写成一个 JSON，注入任何模板，排版一点不乱。

它对 Agent 也友好——让 Claude Code 或 Codex 直接替你跑完整个流程。

开源 MIT。Markdown 写好，剩下交给它。仓库链接在评论区。
