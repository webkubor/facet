# 微信视频号

## 标题

Markdown 教程一条命令变成 PDF 和长图

## 描述

写知识教程的朋友：Markdown 导出的 PDF 排版总是崩？这个开源工具先规划每页放什么知识点，再套视觉模板——一条命令同时生成 A4 PDF 和分享长图，8 套教程模板 + 4 套简历模板任选，颜色还能按自己偏好覆写。MIT 开源，视频里是真实构建过程。

#开源 #效率工具 #知识付费 #内容创作

## 视频

用 launch-kit/video/ 的 60 秒竖版脚本。

## 置顶评论

GitHub 搜 facet 或看主页链接。三条命令上手：clone → pnpm install → pnpm build:all
