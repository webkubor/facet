# SCULPT 人像创作框架

做 AI 出图最大的坑不是模型不够强，而是**提示词太散**。直到把所有 prompt 都按 SCULPT 六要素拆开重写，出图命中率从 30% 提到了 85% 以上。这套方法论就是本手册的全部内容。

## 一、为什么抛弃「自由发挥式」提示词

早期大家都是「灵感型」：脑子里想一个画面，凭感觉写一段描述，扔给 AI 听天由命。结果就是——同样的 prompt 重跑三次，出三张完全不同的图。

整理了 329 条高手 prompt 之后，规律很明确：**所有可控的 prompt 都是填空题，不是作文题。** 它们都从一个固定框架的 6 个槽位出发，往里填具体内容。

这个框架叫 SCULPT——Subject / Composition / Universe / Light / Print / Texture。每个字母对应出图时必须想清楚的一个维度。

## 二、SCULPT 六要素：每个字母填什么

### S — Subject（主体）

画什么？人、物、场景。越具体越好，具体到外貌、姿态、服饰。

✅ 「一位白衣剑客，眉宇冷峻，下颌有一道浅疤，长袍被风吹起」

❌ 「一个剑客」

### C — Composition（构图）

怎么摆？视角、比例、位置、留白、视觉引导线。

✅ 「脸部特写，占画面 70%，侧脸 15 度转向画外，背景虚化」

❌ 「放在中间」

### U — Universe（风格）

什么调性？时代背景、艺术风格、整体氛围。

✅ 「东方电影美学，武侠江湖，旧梦氛围，冷色调」

❌ 「好看的」

### L — Light（光影）

光源方向、色温、明暗对比、景深、氛围感。

✅ 「侧逆光打在发丝上，冷白色温，浅景深 f/2.8，电影级光影」

❌ 「亮一点」

### P — Print（文字）

图上要什么字？用引号包裹，指定位置、颜色、字号。人像特写通常「无文字」，海报才有。

✅ 「顶部居中大字『雪满江湖』，白色楷体，深色水墨背景」

❌ 「写个标题」

### T — Texture（质感）

表面质感、渲染参数、后期风格。

✅ 「Kodak Portra 400 胶片颗粒，保留肤质毛孔细节，85mm f/2.8 浅景深」

❌ 「高清」

## 三、人像创作专项：构图是分水岭

「塑料感」九成来自两件事：大平光 + 全脸居中。反制它们，就靠 C 和 L 两个槽位填对。

| 要点 | 填法 | 为什么 |
|------|------|--------|
| 脸部占比 | 60–75%，肩膀只露一点 | 特写比全身更出氛围，也更不易翻车 |
| 镜头 | 85mm 定焦 + f/2.8（特写 f/1.4） | 85mm 压缩让五官立体，浅景深分离背景 |
| 光影 | 侧逆光 + 发丝高光 | 制造轮廓光，避免大平光的「塑料感」 |
| 背景 | 浅灰 / 奶白 / 冷白，或轻微虚化 | 把注意力锁在人物，别让场景抢戏 |
| 肤质 | 保留毛孔细节，不要磨皮 | 「像胶片写真」和「像 AI」就差这一条 |

全身图才是 AI 最容易翻车的地方（手指、兵器、比例），新手从特写练起，再上全身。

## 四、实战对比：同一需求，两种写法

需求：一张东方武侠人像特写。

❌ 新手写法（30% 命中率）：

「帮我画一个古风武侠帅哥，要帅，要有氛围感」

✅ SCULPT 写法（85% 命中率）：

S：一位白衣剑客的面部特写，眉宇冷峻，眼神看向画外，下颌有一道浅疤

C：脸部占画面 70%，侧脸 15 度，背景虚化的雪夜街巷

U：东方电影美学，武侠江湖，旧梦，冷色调

L：侧逆光打在发丝上，冷白，浅景深 f/2.8

P：无文字

T：Sony A7M4 拍摄，85mm f/2.8，Kodak Portra 400 胶片颗粒，保留肤质细节

填 6 个坑，换一张确定的图。**这是 SCULPT 的全部意义——把「碰运气」变成「下指令」。**

## 五、High / Low 模式：别选错

GPT Image 2 有三种生成模式：

- **High（高精度）⭐ 默认用** —— 严格遵循提示词，文字精准，构图可控。适合人像、产品、海报。
- **Auto（自动）不推荐** —— 模型自行判断，最不稳定，会偷偷切到不想要的风格。
- **Low（创意）** —— 自由发挥，惊喜感强但不可控。仅用于插画、概念图、灵感探索。

90% 的场景用 **High**。

## 六、5 个让出图更稳的进阶技巧

1. **编辑模式：变量与不变量分离。** 多轮编辑时，不变量写明保持不变，变量写明这一轮只改什么，结尾加一句「只改 XXX，不要改变任何其他元素」。
2. **风格一致性：固定片段模板。** 同一系列不同图，把风格段落固定为 prompt 尾部不变部分，只改主体。
3. **文字渲染：3 个关键。** 用引号包裹所有文字；指定位置、颜色、字号；核心文字用引号告诉模型，装饰性文字后期加。
4. **一次只改一个变量。** 结果不理想时，只改一个变量就重试。同时改三个，永远不知道哪个改对了。
5. **Prompt 长度：100–200 字最优。** 过短信息不足，过长模型失焦。

## 七、东方武侠风格词典

风格不是 SCULPT 的事——SCULPT 管「怎么填 prompt」，风格词典管「填什么调性」。两套正交：一个脚手架，一个装修方案。

```text
wuxia cinematic / 东方电影美学 / 武侠江湖 / 旧梦 / 风雪 / 长夜 /
孤灯 / 荒原 / 剑光 / 刀客 / 山鬼 / 冷色调 / 电影级光影
```

## 八、SCULPT 速查卡

**S — Subject（主体）** 具体到外貌、姿态、服饰。

**C — Composition（构图）** 视角 + 比例 + 主体占画面百分比 + 位置。

**U — Universe（风格）** 写实 / 插画 / 3D / 赛博朋克 / 东方美学 / 胶片。

**L — Light（光影）** 光源方向 + 色温 + 景深 + 氛围词。

**P — Print（文字）** 引号包裹 + 位置 + 颜色 + 字号。

**T — Texture（质感）** 渲染参数 + 景深 + 后期风格（胶片颗粒等）。

## 九、行动清单

1. 选一个武侠人物，用 SCULPT 六要素写一版完整 prompt。
2. 重点把 C（构图）和 L（光影）填到具体数值（占比、光圈、光源方向）。
3. 用 High 模式出 4 张，挑中间水平 1 张。
4. 观察发丝、肤质、光影，找出最弱的一个槽位只改它，重试。
5. 把能用的 prompt 存进你自己的素材库，风格段落固定为尾部不变部分。

## 写在最后

SCULPT 不是更花哨的提示词技巧，它本质是**把「我感觉」变成「我指定」**。每填一个槽位，就把 AI 从「猜你想要什么」变成「按你说的做」。

先把 C（构图）和 L（光影）填到具体数值，你会马上看到差别——从「塑料感」到「电影感」，就差这两个槽位。
